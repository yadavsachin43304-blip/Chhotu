# Chhotu

Sachin ka apna Android AI voice assistant.

## v0.1 me kya hai
- Hindi me bolna-sunna (Android Hindi speech + TTS)
- Online dimaag: Groq API (key app ki Settings me daalo)
- Bina internet ke commands: app kholna, contact ko call (pehle confirm), message taiyar karna, alarm, torch, Wi-Fi/Bluetooth/volume settings
- Accessibility se: wapas, home, notifications, recent apps
- Permanent yaaddasht: SQLite me sirf append, delete/update database triggers se band; yaadein app me dikhti hain aur JSON export Downloads/Chhotu me
