# Chhotu v0.5 — अपना दिमाग़, अपनी आवाज़ (बिना API key)

स्थिति: कोड branch `v0.5-dev` में सेव है। **अभी build नहीं किया** (Sachin के कहने पर ही main में जाएगा और APK बनेगा)।

## क्या बदलेगा
1. **दिमाग़ (LocalBrain.kt)**: Google Gemma 4 E2B (Apache-2.0, 140+ भाषाएँ) फ़ोन में, LiteRT-LM से GPU पर (न मिले तो CPU)। एक बार 2 GB डाउनलोड। बातचीत ज़िंदा रहती है (हर बार पूरा prompt दोबारा नहीं) + speculative decoding = तेज़। ऐप खुलते ही दिमाग़ "गरम" होता है।
2. **इंटरनेट समझ (WebSense.kt)**: बिना key के Wikipedia (हिंदी+English) और DuckDuckGo से ताज़ा जानकारी। दिमाग़ ख़ुद तय करता है कब ज़रूरत है (`ACTION web`)।
3. **ख़ुद सीखना (Learner.kt)**: हर 4 बातों के बाद दिमाग़ ख़ुद Sachin के बारे में नई पक्की बातें निकालकर कभी न मिटने वाली यादों में जोड़ता है; "ग़लत किया / आगे से ऐसा करना" जैसी बातें "सबक" बनकर हमेशा याद रहती हैं; हर जवाब से पहले मिलती-जुलती यादें दिमाग़ को दी जाती हैं।
   ईमानदारी: फ़ोन पर model के weights दोबारा train नहीं होते (बहुत भारी), सीखना याद्दाश्त के ज़रिए होता है।
4. **असली आवाज़ (NaturalVoice.kt)**: Kokoro (sherpa-onnx) फ़ोन में, 130 MB, 4 हिंदी आवाज़ें (2 लड़के, 2 लड़कियाँ)। lip-sync वैसा ही चलता है। Sarvam key हो तो वो भी विकल्प।
5. **Gemini सिर्फ़ ऑप्शनल बूस्टर**: default में बंद। key न हो तो भी सब चलता है।
6. Settings: डाउनलोड/हटाओ बटन (resume होने वाला डाउनलोड), आवाज़ चुनो, स्विच। पुराना v0.4 Qwen (1.6 GB) अपने-आप हटेगा।

## तकनीकी बदलाव
Kotlin 2.1.0, compileSdk 35, deps: litertlm-android 0.18.1, coroutines, commons-compress, sherpa-onnx 2.0.1 aar (CI में डाउनलोड)। Manifest: GPU के लिए libOpenCL/libvndksupport, largeHeap.

## जोखिम (build/फ़ोन पर जाँचना)
- 6 GB फ़ोन पर Gemma 4 E2B: ~0.8–1.7 GB RAM; GPU न चले तो CPU धीमा (अंदाज़न 8–15 शब्द/सेकंड)।
- Kokoro की हिंदी अच्छी है पर Sarvam जितनी भावुक नहीं।
- पहला build: library API/कंपाइल त्रुटियाँ ठीक करनी पड़ सकती हैं।
